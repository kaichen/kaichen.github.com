我当前订阅这些AI产品
- ChatGPT Plus $20（从o3-pro发布那个月觉得低于预期后从Pro降级）
- Claude Max 20x $200（从Claude Code支持Pro账户体验过后就掏钱升级）
- Google AI $20（订阅Google One的扩容赠送的）
- Grok Premium $30（推特会员订阅附赠的）

还有各自打折或者赠送的 AI 产品（如 lovable，Warp）更多是体验，不会经常使用。

## 服役中

ChatGPT o3 是我最主力使用的模型产品（注意是在 ChatGPT 里的完整 o3，并非 API 版本），它几乎替代了 99% 日常搜索调研。
它动态的探索能力非常强，简单问题他会在不到一分钟内回答，难题他会持续思考，最长问题我遇到过思考十分钟以上。
原本人工打开一堆网页搜寻再组织信息的探寻过程

Deep Research 现在用的很少，一是时间太长，二是没有合适的产品。ChatGPT 版本搜索网页数太少，而 Gemini 版本搜索太多并且在探寻过程中可能会跑偏（比如探寻 Claude Code 过程中可能会失焦到 Claude 模型的讨论。
当前仅对过往比较容易收敛的概念用 ChatGPT 版本，或者需要广泛搜寻的场景使用 Gemini 版本，往往只有在 o3 搜索调研无法获得答案的时候再进行尝试。

Claude Code 俨然是AI编程唯一选择，包月滚动式限量，靠大量提供给模型上下文实现最好的效果。
因为用的比较多，讨论度很高，我近两个月发推的内容都是关于它。
由于其强大的能力，配合免费的 VSCode 就能有不错的效果，并且我还有免费的 Github Copilot 可以应急辅助。
基于大模型的通用性，大量自动化都可以下自然语音指令让他完成，日常用它来整理文件，处理图片或音视频文件，浏览论坛和 Newsletter 做洞察推荐，用途完全取决于使用者的想象力。

Google Gemini网页我几乎不怎么用，可能是个人偏见或习惯，发现他对上下文关注有些过度，比如我把我的职业告诉他后，他每次回答都会以这个为开头和导向，作为对比 ChatGPT 仅在必要时引用。
反而在AI Studio拿到的免费Key我用在Raycast里采用Gemini-2.5-Flash比较多，不可否认Gemini在API范畴内是综合能力最强的。
其附赠的 NotebookLM 也是非常实用的工具，可以用于对一批自行上传的材料进行 AI 辅助探索。

Raycast 依然是当前本地调用 AI 最便捷的工具，AI Command 是高效；同时其 Snippets 也是最好用的 Prompt 管理器。

简单一句话总计上述的工具，o3 日常调研搜索，以及产出设计或计划；Claude Code 负责处理编程开发以及自动化；Raycast 配合 Gemini 2.5 Flash 处理工作流。

## 退订产品

- Grok 我估计会退订，原本的Grok3 Deep/Deeper Search是非常优秀且市场独一份的推特数据AI搜索，在Grok4推出后关闭这个开关，搜索能力骤降。
- Raycast 好用但已无须付费，在其支持自行设定 API Key [调用AI功能](https://www.raycast.com/core-features/ai)之后，订阅会员没什么意义了，不懂为什么他们把这种重要的收费点给取消掉。
- Cursor 在扩张团队之后明显投入更多资源到产品雕花之后越来越落后。
- Perplexity 这家在2024年风光的企业基本上没有什么产品力，有时连最基础的搜索总结都不行，大量赠送会员营销明显是在刷数据。

## 观点与期待

2025 年是 Agent 年，实际上是属于 Agentic Model，并非套壳产品。
通用 Agent 需要的是连续调用工具以及通过编程创造工具的两个基本能力，当前的 Claude4 已经具备
每次大模型的进步能摧毁许多创业团队一两年的产品开发工作。

现在比较强的一个信念是，2030 年时当前的软件形态会消失，只剩下由大模型厂商提供的 AI 聊天窗口，与数据服务商，界面由 AI 根据上下文即时构建。

下一个期望的重要发布是，箭在弦上的 GPT-5，凭借 OpenAI 的积累相信会又一次抬升智能水平门槛，可能我会因此订阅回 $200 的 Pro 套餐。
